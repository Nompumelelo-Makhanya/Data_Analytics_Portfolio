# 📊 Sales Dashboard

An interactive sales dashboard built in Microsoft Excel to present sales performance and make key trends easier to explore. This project is part of my data analytics portfolio and demonstrates how spreadsheet tools can turn sales data into a clear, stakeholder-friendly report.

## Project files

- [`SALES DASHBOARD.xlsx`](./SALES%20DASHBOARD.xlsx) — Excel workbook
- [`Sales Dashboard (Excel Project).png`](./Sales%20Dashboard%20(Excel%20Project).png) — dashboard preview

## Dashboard overview

The dashboard brings sales reporting into one view, with a focus on:

- Revenue and executive-level KPIs
- Sales trends over time
- Product and regional performance
- Interactive exploration using Excel PivotTables, slicers, and dynamic formulas

Use the dashboard to review overall performance, compare segments, and explore patterns that may support business decisions.

## Tools and techniques

- Microsoft Excel
- PivotTables and PivotCharts
- Slicers and dynamic formulas
- Dashboard design and data visualization
